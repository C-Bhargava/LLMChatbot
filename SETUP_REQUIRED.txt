# IMPORTANT: Setup Required Before Running

Your application now uses environment variables for security. Before running the app, you need to:

## 1. Create a `.env` file in the project directory

Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```

## 2. Edit `.env` and add your actual credentials:

```
FLASK_SECRET_KEY=<generate-a-random-secret-key>
FLASK_DEBUG=True
MYSQL_HOST=localhost
MYSQL_USER=root
MYSQL_PASSWORD=<your-actual-mysql-password>
MYSQL_DB=user_management
```

## 3. Install python-dotenv (if not already installed):

```bash
pip install python-dotenv
```

## 4. Load environment variables in app.py

Add this at the top of app.py (after imports):
```python
from dotenv import load_dotenv
load_dotenv()
```

## Note:
The `.env` file is already in `.gitignore` so it won't be committed to Git.
